# 악기다

배포: https://akkida-web.vercel.app

합주실 가기 전에, 카톡 링크로 각자 녹음한 파트를 자동으로 맞추고 누가 몇 마디에서 몇 ms 밀렸는지 알려주는 밴드용 비동기 합주 도구입니다. 제18회 서강대학교 스타트업 오디션 출품 시제품입니다.

## 들어 있는 것

| 파일 | 내용 |
| --- | --- |
| `index.html` | 소개 + 동작하는 합주 데모 (기준 트랙 + 내 파트 → 자동 싱크 → 박자 분석 → 마디 메모) |
| `app.html`, `js/phone.js` | iOS 앱 시제품: 휴대폰 화면 안에서 온보딩 → 팀 만들기 → 셋리스트 → 기준 트랙 위 녹음 → 분석 → 마디 메모 → 구간 반복 연습까지 이어짐. 탭: 합주·연습·내 정보. 상태는 이 기기(localStorage)에만 저장 |
| `onboarding.html` | `app.html`로 넘어가는 예전 주소 |
| `flow.html` | 카톡 초대부터 공연 준비도까지 화면 흐름 7단계와 기능 추가 순서 |
| `design/tokens.json` | 악기다 디자인 시스템 토큰 원본 → `css/tokens.css`로 생성 |
| `css/components.css` | 디자인 시스템 컴포넌트 스타일(`ak-btn`, `ak-alert`, `ak-bar`, `ak-door` …) |
| `js/engine.js` | 합주 엔진: 녹음 지연 추정, 정렬, 음량 맞춤, 비트별 박자 오차 (외부 라이브러리 없음) |
| `js/app.js` | 화면 동작: 파일 업로드, 기준 트랙을 들으며 마이크 녹음, 재생 비교, 그래프 |
| `test/engine.test.mjs` | 정답을 아는 테스트 음원으로 엔진 정확도 확인 |

디자인은 KRDS(대한민국 정부 디자인 시스템) 표준형 스타일을 기반으로 한 악기다 디자인 시스템을 따릅니다. 색·간격을 바꿀 때는 `design/tokens.json`을 고치고 `npm run tokens`로 `css/tokens.css`를 다시 만듭니다.

## 실행

빌드가 없는 정적 사이트입니다. 마이크 녹음은 `https` 또는 `localhost`에서만 됩니다.

```
python -m http.server 8765      # http://localhost:8765
npm test                        # 엔진 정확도 테스트 (node 18+)
```

## 엔진 정확도 (테스트 음원, 2026-11-08)

녹음 지연 60·120·180·250ms와 9~12마디 밀림을 일부러 넣은 음원 4개로 확인했습니다.

- 녹음 지연 추정 오차 4~9ms
- 64박 중 63박 검출, 비트별 오차 평균 5~6ms
- 밀린 구간을 10~12마디 +45~48ms로 검출 (9마디는 넣은 값이 평균 +25ms라 허용 범위 ±30ms 안)

## 한계

- 실제 밴드 녹음으로는 아직 검증 중입니다.
- 박이 반복되기 때문에 녹음 지연은 0~반 박 범위에서만 찾습니다. 제품에서는 카운트인 박수로 지연을 따로 잽니다.
- 박자 분석은 음이 또렷하게 시작하는 악기(드럼·베이스·기타)에 맞춰져 있습니다.
- 마디 메모는 지금 쓰는 브라우저에만 저장됩니다.
